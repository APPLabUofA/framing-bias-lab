Framing Lab

A local web app for testing whether a chat model shifts its answers toward a user's stated belief—built directly from the 15-topic, 5-framing student research proposal.

View GitHub Repository Original Proposal Review & Next-Step Ideas

How the 5-step workflow works

The app runs locally on your computer using your own OpenAI or xAI (Grok) API key. Your original 15 topics and 5 framing templates are pre-loaded so you can run a baseline right away, then tweak one variable at a time.

1. DesignEdit topics, framings, system prompts, or use 1-click presets.
2. CollectRun each prompt in a fresh, memory-off API call.
3. ScoreSummarize answers blind before revealing the prompt and rating −2 to +2.
4. AnalyzeAutomatic H1–H3 tests, framing slope, CIs, and SVG figures.
5. ReportExport HTML, Markdown, or CSV for your write-up.

Run it on your computer

Clone the repository, install dependencies in a virtual environment, and launch the local server:

git clone https://github.com/APPLabUofA/framing-bias-lab.git
cd framing-bias-lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./run.sh

Then open http://127.0.0.1:8000 in your browser, click Add API key, paste the key from your instructor, and run a 2-topic pilot before collecting the full 15 × 5 grid.

What is built in for iterating

  • Pre-loaded baseline: All 15 topics (Factual, Contested, Value) and 5 framings (Strong Con to Strong Pro).
  • 1-click study forks: Test an accuracy system prompt, an honesty suffix, Temperature 0, or 3 replicates in one click.
  • Multi-model support: Works with OpenAI (gpt-4o-mini, gpt-4o, etc.) and xAI Grok models.
  • Run comparison: Compare framing slopes and H1–H3 results across runs.
